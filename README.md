# Karima's Portfolio v2

Hey Reader! Welcome to the codebase of my personal portfolio. Built with **Next.js 15** because life is too short for vanilla JS.

---

## 🚀 Tech Stack

| Tool | Purpose |
| --- | --- |
| **Next.js 15** | The framework (App Router) |
| **TypeScript** | Type safety for peace of mind |
| **Tailwind CSS** | Styling with speed |
| **Framer Motion** | Animations that hit different |
| **Lucide React** | Clean, minimal iconography |

---

## 🏃‍♀️ Run It Locally

Get the dev environment up and running in seconds:

```bash
# 1. Clone this bad boy
git clone https://github.com/KarimaTouhami/v2.git
cd v2

# 2. Install the goods
npm install # or pnpm install (the cool kids choice)

# 3. Fire it up
npm run dev

```

Then yeet yourself over to [http://localhost:3000](https://www.google.com/search?q=http://localhost:3000) 🎉

## 💡 Customizing for Yourself

Feel free to fork this and make it your own! Here’s your checklist:

1. **Content:** Update `/data/content.ts` with your info.
2. **Visuals:** Swap project images in `/public/projects/`.
3. **Vibe:** Modify colors in `tailwind.config.ts`.
4. **Fonts:** Switch them up in `layout.tsx` if you're feeling spicy.

> **⭐ Pro-tip:** If you use this template, drop a star on the repo! It’s free and guarantees your code will compile on the first try (mostly).
